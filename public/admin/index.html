사용 · 시스템 고정

② 후면 좌우 위치 후면 스티커가 검출된 경우 정상예시와 같은 방향인지 확인합니다.
사용 · 시스템 고정

정상 위치는 차량 후면 기준 오른쪽입니다. 오른쪽은 정상, 왼쪽은 확인필요, 좌우 확정 불가는 판정불가로 처리합니다.

③ 차량 등록데이터 대조 사용자가 입력한 4개 정보가 관리자 차량데이터와 정확히 일치하는지 확인합니다.
필수

성명 · 사번 · 부서 · 차량번호가 모두 일치해야 점검사진을 제출할 수 있습니다. 부서는 관리자 등록데이터에서 자동 생성된 목록 중 선택합니다.

4개 항목 완전일치 → 제출 가능 / 불일치 → 제출 차단
최종 자동판정 범위
• 측면: 스티커 있음 → 정상 / 미검출 → 확인필요
• 후면: 스티커 있음 + 오른쪽 → 정상 / 왼쪽 → 확인필요
• 사용자 정보: 등록 차량데이터 4개 항목 완전일치 필수
• 분석 자체가 불확실한 경우 → 판정불가
