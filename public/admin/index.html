DECISION RULES

자동판정 기준

현재 적용기준 시스템 고정
현재 버전은 필수기능의 안정성을 우선합니다. 아래 4개 기준만 실제 자동점검에 사용하며, 손상률·디자인·크기·임의제작 여부는 최종판정에 사용하지 않습니다.
① 스티커 유무 선택한 차종의 정상예시 스티커 특징을 현재 차량사진 전체에서 직접 탐색합니다.
사용 · 시스템 고정

정상예시 스티커와 충분한 특징점 일치가 확인되면 스티커 있음, 확인되지 않으면 확인필요(미검출)로 판정합니다. 번호판을 사용자가 어떻게 지정했는지는 스티커 유무 판정에 사용하지 않습니다.

적용 기준: 특징점 정합 + RANSAC 일관성 검증 (유효 일치점 8개 이상 및 매칭 품질 기준 충족)
② 후면 좌우 위치 후면 스티커가 검출된 경우 정상예시와 동일한 방향에 부착되었는지 확인합니다.
사용 · 시스템 고정

후면 정상 위치는 오른쪽입니다. 정상예시 차량사진과 현재사진을 자동 정렬하여 방향을 비교하고, 명확히 반대쪽이면 확인필요로 판정합니다.

오른쪽 → 정상 / 왼쪽 → 확인필요 / 좌우 확정 불가 → 판정불가
③ 차량번호 OCR 대조 사용자가 지정한 번호판 영역의 문자를 읽어 입력 차량번호와 비교합니다.
사용

자동판독 결과가 입력 차량번호와 완전히 일치하면 자동으로 일치 처리합니다. 측면처럼 번호판 촬영각도가 큰 경우 OCR이 어려울 수 있으며, OCR 결과는 스티커 유무 판정과 독립적으로 처리됩니다.

완전일치 → 자동 확인 / 불일치·인식실패 → 육안확인
④ OCR 실패 시 육안확인 자동판독이 불확실한 경우 확대 번호판을 사용자가 직접 대조합니다.
허용

OCR 실패만으로 제출을 막지 않습니다. 사용자가 촬영된 번호판과 입력 차량번호가 일치함을 직접 확인하면 제출할 수 있습니다.

OCR은 보조 확인기능이며 스티커 자동판정 결과를 변경하지 않습니다.
최종 자동판정 범위
• 측면: 스티커 있음 → 정상 / 미검출 → 확인필요
• 후면: 스티커 있음 + 오른쪽 → 정상 / 왼쪽 → 확인필요
• 분석 자체가 불확실한 경우 → 판정불가
제외 기준: 구조 손상지수, 구조 보존율, 디자인 동일성, 기존 부착위치 유사도, 후면 크기차이, 색상차이, 임의제작 판정. 필요 시 향후 별도 기능으로 추가합니다.
